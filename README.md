# Morrow HR

Morrow is a frontend-only people operations workspace for employee records, attendance, leave requests, and payroll planning. This repository is being built as a multi-page React application with realistic demo data and in-memory state.

## Run locally

- Install dependencies: `npm install`
- Start Vite: `npm run dev`
- Run ESLint: `npm run lint`
- Create a production build: `npm run build`

Changes made in the demo will reset when the page is refreshed. No backend or browser storage is used.
